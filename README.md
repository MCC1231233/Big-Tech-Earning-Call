# Big Tech Earnings Call Tracker

미국 빅테크(Magnificent 7) + 삼성전자·SK하이닉스의 **분기 실적을 AI Capex ↔ HBM/메모리 수요 관점**에서 추적하는 살아있는 보고서입니다.

- **보고서**: [`earnings-tracker.html`](earnings-tracker.html) — 실적 캘린더 · 빅테크 AI Capex · 한국 메모리 · 빅테크 기업 카드 · DD 시사점 · 업데이트 로그
- **발행 아티팩트**: https://claude.ai/code/artifact/1f0ff68a-eb99-42cd-a25e-21b1ef3c426c

## 운영 방식
- 실적이 발표될 때마다 각 기업 카드의 상태가 `🕒 발표 전 → ✅ 발표`로 바뀌고, 컨센서스 수치가 실측치로 교체됩니다.
- 새 분기 실적 시즌(≈ 1·4·7·10월)이 열리면 새 분기 섹션이 추가됩니다.
- 매 갱신은 문서 하단 **업데이트 로그**에 버전과 함께 기록됩니다.

## 초점
1. AI Capex / HBM·메모리 수요 연결고리
2. 실적 숫자 & 가이던스
3. 컨콜 코멘트 & 투자 시사점

> 본 자료는 공개 보도·리서치를 요약한 투자 참고용이며, 개별 종목 매매 권유나 투자자문이 아닙니다. 발표 전 수치는 추정치입니다.
